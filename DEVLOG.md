## 18.08.2026 (вечер)

- **Форма нового дела — явное управление раскрытием**: раньше раскрытие держалось на фокусе
  и клик вне полей мгновенно сворачивал форму с потерей ввода. Теперь форма раскрывается при
  входе в любое поле и сворачивается только явно: кнопки «Добавить» (сохранить) и «Выйти»
  (без сохранения), клавиши Enter (добавить) / Esc (выйти). В заметке Enter — перенос строки.
  Под кнопками подсказка про клавиши. После отмены дата автоматически восстанавливается по
  контексту списка (prefillDateInput при раскрытии). Полный сброс полей вынесен в
  resetAddForm() (включая важность).

Версии: style.css?v=16, main.js?v=14

## 18.08.2026 (вторая половина сессии, переход через полночь с 17.08)

- **Ширина приложения**: убран `max-width: 1280px` — приложение на всю ширину, поля по бокам, поля по бокам
  40px (сначала 30px, затем увеличено до 40). Открытый таймлайн сдвигает контент влево
  (`body.timeline-open .app { margin-right }`), на ≤960px — перекрытие без сдвига.
- **Анимация таймлайна**: двухслойная — панель 0.45с с мягкой кривой, проявлением и тенью;
  заголовок/дата доезжают с задержкой 60мс, список часов — 100мс (эффект глубины).
- **Время у задач**: поле «Длительность» заменено на «Время окончания» (форма + редактор).
  Хранится `endTime`. Бейдж на карточке и чипе: «12:00–13:30». Валидация: окончание строго
  позже начала. Миграция старых `duration` (минуты) → `endTime` при загрузке.
- **Фикс добавления на таймлайн**: (1) время с «некруглыми» минутами (14:20) теперь снапится
  в получасовую строку через `timeToRow()` — раньше терялось; (2) задача со временем, но без
  даты автоматически датируется сегодняшним днём (форма и редактор).
- **Таймлайн — базовая функциональность**: кнопка с часами рядом с календарём (44×44),
  выезжающая панель, 24 часа → 48 получасовых строк, подсветка текущего получаса «сейчас»,
  линия текущего времени с меткой минут (двигается раз в 30с), закрытие: повторный клик по
  кнопке / шеврон / Esc. Живое обновление панели при изменении задач (через render()).
- **Драг на таймлайн**: задача из списка или чип → в получасовую строку (назначается дата и
  время), в блок «без времени» (снимается время). Проверяется только вручную (см. AGENTS.md).

Версии: style.css?v=15, main.js?v=12
