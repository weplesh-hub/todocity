# 🥗 КалКалк — трекер калорий и воды

Простое одностраничное веб-приложение без зависимостей и сборки: чистые HTML + CSS + JS.
Считает калории и белки/жиры/углеводы по приёмам пищи, отслеживает количество выпитой воды, показывает историю за 14 дней.

> Английская раскладка не требуется 🙂 Интерфейс полностью на русском.

## Возможности

- **Дневник** с навигацией по датам (вчера / сегодня / любой прошлый день)
- **Кольца прогресса**: калории и вода с подсчётом остатка или перебора
- **База продуктов** (~65 наименований на 100 г) с поиском и автоподстановкой КБЖУ
- **Быстрые кнопки** для частых продуктов (банан, яйцо, кофе…) и воды (+100/+250/+500 мл)
- **Макронутриенты**: белки/жиры/углеводы с целевыми барами
- **История** за 14 дней со средними значениями, клик по дню открывает его в дневнике
- **Расчёт нормы калорий** по формуле Миффлина — Сан Жеора (пол, возраст, рост, вес, активность, цель) и воды (30 мл × вес)
- **Светлая/тёмная тема**, адаптивная вёрстка (удобно с телефона)
- **Экспорт/импорт** всех данных в JSON, полный сброс

## Запуск локально

Вариант 1 — просто открыть `index.html` двойным кликом (данные хранятся в браузере и так).

Вариант 2 — через локальный сервер (рекомендуется):

```bash
cd PROJECT_CalCalk
python -m http.server 8123
# открыть http://127.0.0.1:8123
```

## Где хранятся данные

В `localStorage` браузера, ключ `calcalk_v1`. Ничего не отправляется ни на какие серверы.
Для переноса между устройствами/браузерами: Настройки → Экспорт (JSON) → на другом устройстве Импорт.

## Публикация на внешний сервер (когда будете готовы)

Это чистая статика — достаточно скопировать три файла (`index.html`, `styles.css`, `app.js`) на любой хостинг:

- **свой сервер / VPS**: отдать папку через nginx/Apache как статические файлы;
- **GitHub Pages / Netlify / Vercel**: просто указать папку, нулевая конфигурация.

## Идеи развития

- PWA: манифест + service worker → установка на телефон и офлайн-работа
- Синхронизация между устройствами (небольшой backend с аккаунтами)
- Своя база продуктов пользователя, штрихкоды
- Графики динамики веса и калорий
